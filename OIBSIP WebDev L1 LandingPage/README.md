# NovaFit Landing Page

## Internship Project

A responsive static landing page built with:

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Responsive media queries
- No JavaScript

## Files

- `index.html` — page structure and content
- `style.css` — complete visual styling and responsive layout

## How to run

1. Download/extract the project folder.
2. Open `index.html` in a web browser.
3. Resize the browser window to test the responsive mobile layout.

## Project requirements covered

- Sticky navigation bar
- Four navigation links
- Hero section with headline, subheading and CTA
- Features section
- About section
- Additional CTA section
- Footer with contact/social placeholders
- Consistent colour palette
- Responsive Flexbox/Grid layout
- Intentional spacing and box sizing
- Multiple typography sizes
- Semantic HTML5 elements

Note: NovaFit is a fictional concept brand created for the internship project.
