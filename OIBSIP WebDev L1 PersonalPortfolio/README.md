# Vincent Hagan - Personal Portfolio

## Project Overview

This is a responsive personal portfolio website created for an internship portfolio assignment.

The website showcases:
- Profile / hero section
- About Me section
- Technical skills using Font Awesome icons
- Project cards with imagery backgrounds and lightbox modal view
- Interactive JavaScript features (dark/light mode, mobile menu toggle, scroll progress indicator)
- Contact information
- Smooth-scroll navigation
- Responsive desktop, tablet and mobile layouts

## Technologies Used

- HTML5
- CSS3 (Variables, Flexbox, CSS Grid)
- JavaScript (ES6+)
- Font Awesome Icons CDN
- Google Fonts
